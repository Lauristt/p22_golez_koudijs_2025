# Project overview

## Economic question

Does rising equity duration help explain why expected returns dominate valuation variation after 1945? The replication will connect evidence from short-duration dividend strips, long historical market series and payout-sorted stock portfolios.

## Current stage

A local Python translation now generates the assigned baseline tables and figures from Mendeley version 1. All 263 independently recomputed numeric table entries agree with published rounding. Three Table 4 smoothing entries remain explicitly labeled supplied constants because their estimation file is absent. The local report is generated at `_output/replication/index.html`; restricted inputs and generated results are not included in this documentation site.

## Deliverables

Tables 1, 2, 4, 5, 6, 7 and Figures 1, 3; a recent-sample update; original data validation exhibits; an instructor-approved extension; a generated LaTeX report and a cleaned-data tour notebook.

## Version and data lineage

The instructor-linked published PDF reports JFE volume 172, article 104114. The assignment lists volume 171. Its Table 5 shows postwar, prewar and full-sample columns.

The pipeline downloads the [authors' data and code package](https://data.mendeley.com/datasets/fp6fryn7h3/1). Track the version, retrieval date, transformations and permitted use of each input. CRSP/Compustat data require WRDS access and must not be redistributed here.
